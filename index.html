03 / Three things I learned

A few ideas that clicked

01

Workflow, Agent, Tools

A workflow is written instructions or a step-by-step process to follow to complete a task. The agent understands those instructions and decides what to do with them. Tools—such as scripts or apps—do the actual work.

02

MCP

MCP is a standard way for Claude to connect to, or get access to, external tools and data.

03

Skills and projects

Skills are instructions for how to do a task, and a project holds the files.

04 / How we work

From a branch to a live page

I create a branch where I can build and check my changes.

I commit a snapshot of what I changed and push it to GitHub.

I open a pull request to ask for the branch to be merged into main.

Will reviews it and asks for additional fixes if needed.

Once it’s reviewed with no more fixes needed, Will merges it into main.

Vercel deploys main, so the page goes live.
