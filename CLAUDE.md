# claude-code-practice

Ed's landing page about what Ed learned setting up Claude Code. It is one static page:
`index.html` (plain HTML and CSS, styles inside the file) plus an `images` folder. No
frameworks, no build step, no npm, no JavaScript libraries. The repo is public, so never add
secrets or private company information.

## Preview

Open `index.html` directly in a web browser. No server or build is needed. Check it at
phone width as well as laptop width.

## Deploy

Vercel deploys the site from the `main` branch. Work on a feature branch and open a pull
request; Will reviews and merges, then Vercel publishes `main`.
